# Athenas_X_Reader_System
Athena's X Reader System allows fan fiction authors to create "x reader" fics that use reader chosen pronouns, and names.

When writing your fan fic use the following codes to be compatible with the system

| Code | Replacement Word | Case Sensitive Support |
|-------|--------|--------|
| y/n | first name | No (always uppercase) |
| y1p | he/she/they/custom | Yes ( Y1P or Y1p will be uppercase) |
| y2p | him/her/them/custom | Yes ( Y2P or Y2p will be uppercase) |
| y2p | his/hers/theirs/custom | Yes ( Y3P or Y3p will be uppercase) |
| yfn | formal/full name | No (always uppercase) |
| yhn | honorific name | No (always uppercase) |

For example Jane is reading a fan fic that uses this system her pronouns are she/her/hers her full name is Jane Watts Smith and her honorific name is Dr. Smith. This is what a fan fic author would right:

`y/n was walking down the hallway when y1p saw a wallet on the floor. Y1p picked up and opened it to see who it belonged to. Y1p did not recognize the owner so y1p took it to lost and found. "yhn what can I do for you?" Mr. Dallas asked as y1p entered the font office.`

This is what Jane would see after setting up the system:

`Jane was walking down the hallway when she saw a wallet on the floor. She picked up and opened it to see who it belonged to. She did not recognize the owner so she took it to lost and found. "Dr. Smith what can I do for you?" Mr. Dallas asked as she entered the font office.`
