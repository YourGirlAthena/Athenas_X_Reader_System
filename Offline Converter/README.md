To use the "offline" version of the software you need to use matlab. I know its not ideal but its the language I have the most experience with. I will try to switch over to java script next time. 

How to use:
1. Make .txt file with the fic and place in the same directory as the .m file.
2. Open the .m file in matlab.
3. Change put the name of your text file where it says "test_test.text" in line 109. make sure to keep the quotations where they are.
4. Change the name of output file in line 154 just like the previous step. Make sure its name is different than your original fic file.
5. Hit the Run button (green triangle) in the Editor tab.
6. Type in your name and pronouns then hit ok. The text input for your name and pronouns are case insensitive, the program will automatically generate the correct casing following the code chart.
